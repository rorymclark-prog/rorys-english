# Select a lesson or unit without filling teaching forms

30 October 2026. Student and lesson/unit selectors remain the main setup. The activity, objective and source are filled from the selected unit/preparation. A directly opened document uses its filename and document-led teaching instructions rather than retaining a generic conversation task. Approved PDFs also set a matching unit teaching focus.

Search fields are removed from both lesson selectors. Teaching activity, listening focus, source text, AI speed/speaker controls, audio configuration and tracking overrides are optional closed disclosures. The existing AI consent checkbox remains visible and must be acknowledged; it is never silently checked. Unit overviews remain labelled as overviews and are not represented as full textbook exercises.

Validation includes the existing release suite plus a real-component test that selects a unit and starts with the exact unit activity, objective and source without entering any text. No credential, sharing, student-record or lesson-file changes.
